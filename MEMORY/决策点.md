# 决策点.md

## 已做决策

| 决策 | 原因 | 时间 |
|------|------|------|
| 首屏 Hero 拆分为层级标题 + 数据条 + 计时徽章 | 提升视觉冲击力和信息层级，让首屏更吸引人 | 2026-07-06 |
| 递进式入场动画（eyebrow → 前缀 → h1 → 数据 → 描述 → 按钮 → 指示器） | 引导视线依次扫过内容，制造"打开幕布"的叙事感 | 2026-07-06 |
| 右上角参考圈速徽章（6:48.047） | 用具体数字建立"这里很严肃"的赛车氛围，为圈速档案页做入口暗示 | 2026-07-06 |
| 抽象赛道轮廓作为装饰 SVG | 增加首屏的视觉肌理和地理识别感，无需额外图片加载 | 2026-07-06 |
| 按钮 hover 增加 scale(1.02) + 上浮 | 微交互动效让 CTA 更有"被按下"的反馈感 | 2026-07-06 |
| primary-button + ghost-button 增加 focus-visible 焦点环 | 满足 WCAG 2.1 AA 键盘导航可访问性 | 2026-07-06 |
| Logo 路径统一为 `/logos/`（绝对路径） | 避免不同页面路径下 404 | 2026-07-06 |
| 删除 `logos/color/` 目录 | 所有 Logo 统一使用白色 SVG 版本，深色背景下可见 | 2026-07-06 |
| InfoBlock 提取为公共组件 | 消除 BrandDetailPage 和 CornerDetailPage 的重复代码 | 2026-07-06 |
| LapTimes 导航改用 `<Link>` | 正确的 React Router 导航方式 | 2026-07-06 |
| 首页重设计方向暂定为 `方案 A + B 混合` | 保留入口系统的清晰度，同时引入更强的杂志式排版气质，避免首页像后台或纯海报 | 2026-07-08 |
| 首页文案收紧，减少“中二”和自我抒情表达 | 用户更希望首页像清晰入口，而不是热爱过度外露的自我表达 | 2026-07-08 |
| 放弃上一版首屏右侧入口面板，改为“大标题 + 赛道轮廓主视觉 + 底部事实栏” | 上一版首屏同时承载标题、数据、纪录、弯角入口，信息角色过多；新版先建立识别度和入口，再把详细内容交给第二屏与地图页 | 2026-07-08 |
| 路由从 `HashRouter` 切换到 `BrowserRouter`，部署端使用 SPA fallback | 子页面需要能直接访问、刷新和分享；Netlify 已有 fallback，Vercel 通过 `vercel.json` 补齐 rewrite | 2026-07-09 |
| 圈速口径统一以官方成绩为准（M4 CSL 7:18.137、Huracán Performante 6:52.01、Aventador SVJ 6:44.97） | 车型详情页与官方资料一致；避免同一车型在圈速表和品牌/车型页出现多个数字却不说明口径 | 2026-08-16 |
