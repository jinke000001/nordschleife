# PRD —— 纽北赛道中文指南：前端优化与作品集打磨

> 版本 v1.0 · 2026-08-30 · 规划：Kimi 客户端 · 执行：Kimi Code

---

## 1. 问题是什么

网站结构已完整（8 页面 + 独立数据层 + 代码分割），但作为"个人作品"还存在三类短板：

1. **工程债**：`npm run build` 耗时 4 分 25 秒，拖垮迭代；`src/styles.css` 单文件 5512 行，全站样式混杂，维护困难；README 引用了已重构掉的旧路径。
2. **体验缺口**：首屏 LCP 未做优化（35 MB 图片资源、无 preload 策略）；动效未做 `prefers-reduced-motion` 降级；移动端体验未系统性回归。
3. **作品感缺失**：`index.html` 只有基础 title/description，无 Open Graph / Twitter Card / favicon，分享到社交平台无预览卡片；整体缺少"作品级"的完整度收尾。

## 2. 成功标准

| 指标 | 现状 | 目标 | 验证方式 |
|------|------|------|----------|
| `npm run build` 耗时 | 4m25s | ≤ 60s | 本地掐表 |
| 首屏 LCP（本地 preview，3G 节流） | 未测 | ≤ 2.5s | Lighthouse |
| Lighthouse 性能分（移动端） | 未测 | ≥ 90 | Lighthouse |
| Lighthouse SEO 分 | 未测 | = 100 | Lighthouse |
| 分享预览 | 无卡片 | 微信/Twitter 粘贴链接有标题+图+描述 | 手动验证 |
| 动效降级 | 无 | 开启系统"减少动态效果"后页面无大幅动画 | 手动验证 |

## 3. 范围

**做**：构建提速、样式拆分、SEO 元信息、首屏性能、动效降级、移动端回归、文档修正。

**不做**（本期）：内容新增/改写（车型文案、弯角故事补全）、新增页面或功能、视觉风格重设计、部署链路变更、引入新框架（不换 Tailwind、不上 TS——见决策点）。

## 4. 约束条件

- 执行方为 Kimi Code，任务文档必须自包含：写明文件路径、改法、验收命令。
- 每个任务独立可交付、可回滚，执行前先 `git status` 干净，完成后单独 commit。
- 不删除任何现有内容数据（`src/data/` 只读）。
- 视觉风格维持现状（沥青灰 + 纽北红暗色主题），本期只做体验优化不做重设计。
- 中文内容、面向中文访客；站点为纯静态 SPA，无后端。

## 5. 初步方案（三期）

### 第一期：工程基础（本周）
- T1 构建提速诊断与修复

### 第二期：样式与性能
- T5 `styles.css` 按页面/组件拆分

### 第三期：体验回归
- T7 移动端细节回归（抽屉、触控、横屏）
